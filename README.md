# BeaconRadio

BeaconRadio: a shared live radio for Subnautica 2 servers that use the Beacon launcher.

Everyone on the server hears the same live station coming from one spot in the world. It gets quieter with distance and moves left/right as you turn. Anyone can move the radio or change the station for everyone. Changes are synced through the Beacon server's chat API.

- `BeaconRadio-0.1.0.zip`: the mod folder only, for the Beacon server's required-mods list (the launcher installs it automatically).
- `BeaconRadio-for-friends.zip`: manual install. Extract it and run `Install-BeaconRadio.bat`.

Controls (game window focused): Ctrl+Alt+H move radio here, Ctrl+Alt+S next station, Ctrl+Alt+O on/off, Ctrl+Alt+I what's playing, Ctrl+Alt+M mute, Ctrl+Alt+PageUp/PageDown volume.
